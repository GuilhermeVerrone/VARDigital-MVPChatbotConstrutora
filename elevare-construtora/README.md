# Elevare Construtora (projeto fictício)

Pasta de projeto com o site estático, a identidade visual e os três empreendimentos da construtora fictícia **Elevare**.

## Como abrir
Dê dois cliques em `index.html`. Não precisa de servidor.

## Estrutura
```
index.html                      Página institucional
marca.html                      Identidade visual (logo, cores, tipografia, aplicações)
empreendimentos/                Uma página por empreendimento
  lumen-urban.html
  parc-verde.html
  altomare.html
css/style.css                   Estilos do site
assets/
  logo/                         Logos e símbolo (SVG e PNG)
  marca/                        Paleta, cartão de visita, papel timbrado, placa de obra
  empreendimentos/<nome>/       Fachada e 3 plantas de cada empreendimento (SVG e PNG)
```

## Identidade
- Verde Elevare `#0F3D36` (base, 60%)
- Lima `#B5D86A` (apoio, 30%)
- Coral `#F4623A` (destaque, 10%)
- Neutro de fundo: off-white `#F3F1E7`
- Tipografia: Inter (Google Fonts, com fallback para fontes do sistema)

## Empreendimentos
| Empreendimento | Cidade | Plantas |
|---|---|---|
| Lumen Urban | Curitiba · PR | Studio 28 m², 1 dorm 39 m², 2 dorm 52 m² |
| Parc Verde | Campinas · SP | 2 dorm 68 m², 3 dorm 89 m², suíte master 112 m² |
| Altomare | Balneário Camboriú · SC | 3 suítes 150 m², 4 suítes 195 m², cobertura 280 m² |

Tudo é fictício: empresa, endereços, telefones, nomes e imagens. As plantas são ilustrativas e foram desenhadas em SVG.
